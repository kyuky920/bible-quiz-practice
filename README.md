# 말씀 한 장 — 광흥교회 성경 퀴즈

2026 광흥교회 전교인 성경퀴즈대회 2차 예상문제집을 바탕으로 만든 사도행전 연습 사이트입니다.

- 사도행전 1–28장, 전체 50문제 모두 4지선다 객관식
- 매회 전체 50문제를 중복 없이 무작위 출제, 객관식 보기 순서 무작위 변경
- 한 문제당 2점, 총 100점
- 원문 주관식 8문제도 정답과 학습용 오답 보기를 제공하며 자동 채점
- 원문 문제 번호와 성경 구절, 점수와 최종 결과 표시

## 실행

별도 설치나 빌드 없이 정적 파일로 동작합니다.

```sh
python3 -m http.server 4173 --directory dist
```

브라우저에서 http://localhost:4173 으로 접속합니다.

## 수정 및 배포

- `dist/questions.js`: 문제·보기·정답·성경 구절
- `dist/app.js`: 무작위 출제와 채점
- `dist/index.html`, `dist/styles.css`: 화면

GitHub 저장소의 Settings → Pages → Source를 GitHub Actions로 설정합니다.
main 브랜치에 변경 사항을 올리면 GitHub Pages에 자동으로 배포됩니다.

문제와 정답은 제공된 예상문제집 기준입니다. 원문 주관식 8문제의 오답 보기는 연습을 위해 추가했으며 정답은 그대로 유지했습니다.
